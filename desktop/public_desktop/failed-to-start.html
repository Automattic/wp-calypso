How to bypass your proxy for this app

The app only uses your Mac’s proxy when Proxy is set to Use system proxy in WordPress.com › Preferences.... If you don’t need a proxy to reach WordPress.com, choose No proxy there and restart the app.

If you do use a system proxy, make sure it is running, then exclude WordPress.com from it:

  1. Open the Apple menu and choose System Settings
  2. Click Network in the sidebar
  3. Click the connection you’re using (probably Wi-Fi)
  4. Click Details...
  5. Click Proxies (you may need to scroll down)
  6. Add , wordpress.com, *.wordpress.com, *.wp.com to the end of Bypass proxy settings for these hosts & domains - the leading comma is important
  7. Click OK, then quit and reopen the app
