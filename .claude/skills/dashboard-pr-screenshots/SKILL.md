# Dashboard PR Screenshots Skill

Captures before/after screenshots of dashboard routes affected by PR changes and updates the PR description with side-by-side comparisons.

## Usage

Run `/dashboard-pr-screenshots` to:
1. Detect which routes are affected by current branch changes in `client/dashboard/**`
2. Capture "before" screenshots from trunk via calypso.live
3. Capture "after" screenshots from PR branch via calypso.live
4. Update PR description with comparison images

## Manual Route Override

You can specify routes manually instead of auto-detecting:
```
/dashboard-pr-screenshots /sites/example.com /me/profile
```

## How It Works

### Step 1: Detect Changed Files
Get files changed in the current branch:
```bash
git diff origin/trunk...HEAD --name-only -- 'client/dashboard/**'
```

### Step 2: Map Files to Routes
Use the route detector script to map changed files to dashboard routes:
```bash
node client/dashboard/bin/dashboard-route-detector.mjs
```

**Directory-to-Route Mapping:**

| Directory | Route |
|-----------|-------|
| `client/dashboard/sites/overview` | `/sites/$siteSlug` |
| `client/dashboard/sites/backups` | `/sites/$siteSlug/backups` |
| `client/dashboard/sites/settings` | `/sites/$siteSlug/settings` |
| `client/dashboard/sites/deployments` | `/sites/$siteSlug/deployments` |
| `client/dashboard/sites/monitoring` | `/sites/$siteSlug/monitoring` |
| `client/dashboard/sites/logs` | `/sites/$siteSlug/logs` |
| `client/dashboard/me/profile` | `/me/profile` |
| `client/dashboard/me/billing` | `/me/billing` |
| `client/dashboard/me/security` | `/me/security` |
| `client/dashboard/domains` | `/domains` |
| `client/dashboard/emails` | `/emails` |
| `client/dashboard/plugins` | `/plugins` |

**Shared Components:** When files in `client/dashboard/components` or `client/dashboard/app` change, screenshot these priority routes:
- `/sites`
- `/sites/$siteSlug`
- `/domains`
- `/domains/$domainSlug`
- `/emails`
- `/plugins`
- `/me`

### Step 3: Capture Screenshots
Run the screenshot capture script:
```bash
node client/dashboard/bin/dashboard-pr-screenshots.mjs --routes "/sites,/me/profile"
```

The script will:
1. Launch Playwright browser
2. Authenticate using E2E test account
3. For each route:
   - Screenshot trunk version via `calypso.live?branch=trunk`
   - Screenshot PR branch version via `calypso.live?branch=$BRANCH`
4. Upload images to GitHub
5. Return markdown for PR description

### Step 4: Update PR Description
Use `gh pr edit` to append the visual regression section to the PR description:
```bash
gh pr edit --body "$(cat updated-body.md)"
```

## Prerequisites

- Active PR on the current branch
- `gh` CLI authenticated
- E2E test secrets available (for calypso.live authentication)
- Playwright installed

## Troubleshooting

**No routes detected:** Ensure your changes are in `client/dashboard/**` directory.

**Screenshots failing:** Check that calypso.live previews are available for both trunk and your branch.

**PR update failing:** Verify `gh` CLI is authenticated with `gh auth status`.
