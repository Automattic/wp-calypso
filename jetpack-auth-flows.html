Jetpack Auth Flow Test URLs

Prerequisites: Calypso must be running at http://calypso.localhost:3000. You must be logged in to WordPress.com in the same browser. The URLs below use fake nonce/secret values — the authorize form will render, but actual authorization will fail (which is fine for UI testing). To test a real end-to-end flow, initiate from your Jetpack-connected test site.
