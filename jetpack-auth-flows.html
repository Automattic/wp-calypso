Jetpack Auth Flow Test URLs

Prerequisites: Calypso must be running at http://calypso.localhost:3000. You must be logged in to WordPress.com in the same browser. The URLs below use fake nonce/secret values — the authorize form will render, but actual authorization will fail (which is fine for UI testing). To test a real end-to-end flow, initiate from your Jetpack-connected test site.

1. Jetpack Connector — single plugin (Jetpack Boost)

Open jetpack-connector flow with plugins=jetpack-boost

2. Jetpack Connector — multiple plugins

Open jetpack-connector flow with plugins=jetpack,jetpack-boost

3. Jetpack Connector — Jetpack Social

Open jetpack-connector flow with plugins=jetpack-social

4. Jetpack Connector — unknown plugin (fallback branding)

Open jetpack-connector flow with plugins=some-unknown-plugin (should fall back to Jetpack branding)

5. Original jetpack-onboarding flow (comparison)

Open original from=jetpack-onboarding flow (should look the same as before)
