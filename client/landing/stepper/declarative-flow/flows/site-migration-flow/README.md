## Static site import

With `migration/static-site-import` enabled, only `ref=move-lp` routes through the static-site review and progress steps. The session API does not provide entitlement information, so the existing upgrade-plan boundary remains in place for destinations without `install-plugins`. A backend/product entitlement contract is required before that boundary can be removed.
