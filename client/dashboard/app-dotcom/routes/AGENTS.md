# app-dotcom/routes — Experimental

This directory is a prototype of a new layout for the dashboard's routes, screens and route tests. The layout isn't adopted yet, and the code here may change or be removed.

- Don't add routes, screens or tests here unless the task is about this layout.
- Dotcom's routes still live in `client/dashboard/app/router/`, and its screens in the feature areas (`client/dashboard/sites/` and others). Put new work there.
- Don't import from this directory outside it.
