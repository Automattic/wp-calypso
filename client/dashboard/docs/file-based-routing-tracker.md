# File-based routing tracker

Progress of the [file-based routing migration](./file-based-routing.md). One row per route file in `client/dashboard/routes/`. A row lists every current definition that ends up in that file: the dotcom and A4A definitions of a shared `/sites` URL merge into one file.

- **Apps**: which apps include the route today.
- **Current definition**: route variable and location in `app/router/` when this tracker was generated (trunk at `b23103f87c0`). Line numbers drift as Phase A lands; search by variable name.
- **Calypso reuse**: a Calypso router in `client/sites/v2` or `client/my-sites/purchases/v2` reuses this route (decision 11).
- **A** / **C**: status in Phase A and Phase C: `todo`, `in progress (<branch>)` or `done (#<PR>)`.

Rows are grouped in Phase A order. Within a group, migrate parents before children.
