# Theme

A library of React components designed for use in Automattic products.

## Installation

```bash
yarn add @automattic/theme
```

## Development Workflow

This package is developed as part of the Calypso monorepo. Run `yarn`
in the root of the repository to get the required `devDependencies`.

### Tests

`yarn run test-packages`

`yarn run test-packages:watch`

### Using [Storybook](https://storybook.js.org/)

To see stories within this package, run `yarn workspace @automattic/theme run storybook:start`.
