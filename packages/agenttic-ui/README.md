# @automattic/agenttic-ui

UI components for the Agenttic framework.

## Installation

```bash
pnpm install @automattic/agenttic-ui
```

## Usage

```typescript
import { /* components */ } from '@automattic/agenttic-ui';
```

## Development

```bash
# Install dependencies
pnpm install

# Build the package
pnpm build

# Run in development mode
pnpm dev

# Run tests
pnpm test

# Type check
pnpm type-check
```
