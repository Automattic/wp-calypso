## Summary

Adds a hover effect to the benefits section of the Domain Connect/Transfer card to improve visual feedback when users interact with the card.

## Changes

- Added a `:hover` pseudo-class to `.option-content-v2` that changes the background color of the benefits section (`.option-content-v2__benefits`) from `#fafafa` to `#f3f6fc` when hovering over the card.
